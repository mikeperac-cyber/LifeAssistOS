# LifeAssistOS 0.4.1

This release brings the Dashboard closer to the reference design: a charcoal workspace with violet, rose, and gold accents, a denser three-column layout, and clearer visual hierarchy.

## Dashboard

- Added seven-day completion bars with visible zero-day tracks.
- Added goal progress rings based on completed linked tasks, plus a count of tasks completed this local month.
- Added an in-progress task row with completion controls and a working Add task tile.
- Migrated the prior Forest palette preference key without discarding saved theme choices; Midnight remains the default for new installs.
- Reordered the default dashboard while preserving user-customized layouts.

## Navigation and Documents

- Grouped the sidebar into Apps, Integrations, and System, with shortcuts to Calendar and AI provider settings.
- Added a local Documents library for PDF, Office, text, spreadsheet, presentation, and image files. It stores file links, so originals remain in their folders.
- Document links are local to the device and excluded from local backups and encrypted folder sync.
