# AI Productivity Features Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add user-reviewed AI task capture, subtask suggestions, and daily planning using the provider and encrypted API-key configuration already in Mike Assist.

**Architecture:** A small core service sends bounded prompts through the existing `Provider.chat` interface and validates JSON responses before returning suggestions. Typed IPC exposes only these three non-mutating AI operations; the renderer owns review and save actions.

**Tech Stack:** TypeScript, existing Zod schemas, existing provider factory, Electron typed IPC, React, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-08-todo-ai.md`

## Global Constraints

- Reuse existing provider presets, model, endpoint, API-key form, `SettingsStore`, `safeStorage`, and provider factory.
- AI requests use no tools and cannot mutate tasks, access integrations, or perform external actions.
- Task suggestions must be editable and confirmed by the user before saving; daily planning never changes task data.
- Send only the text/task fields required for the selected AI action.
- Ordinary task management remains available without an AI provider.

## Review Focus

- Relative dates must use the provided local date and time zone — test `test_task_draft_uses_supplied_local_date_and_timezone` in Task 1.
- Malformed or schema-invalid model output must not reach storage — test `test_invalid_ai_json_is_rejected` in Task 1.
- Daily-plan IDs must refer only to supplied tasks and must not repeat — test `test_daily_plan_rejects_unknown_and_duplicate_task_ids` in Task 1.
- Provider failure or missing credentials must leave the Tasks view usable — test `test_ai_unavailable_does_not_disable_local_task_actions` in Task 3.
- AI suggestions must remain proposals until the user confirms — test `test_ai_suggestions_require_explicit_save_action` in Task 3.

- `src/shared/todo-ai.ts` — shared request and result types.

- `src/main/index.ts` — calls the configured provider through `providerFrom`.

- `src/preload/index.ts` — narrow AI methods exposed to renderer.
- `src/renderer/src/components/TodoAiActions.tsx` — capture, breakdown, and plan review UI.

- `src/renderer/src/App.tsx` — pass provider readiness and Settings navigation into Tasks.
- `src/renderer/src/styles.css` — responsive AI review panel styles.
- `tests/todo-ai.test.ts`, `tests/todo-ai-ipc.test.ts`, `tests/todo-ai-ui-model.test.ts` — parsing, route, and confirmation behavior.
