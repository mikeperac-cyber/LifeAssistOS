# AI Productivity Features Spec

## Goal

Add focused AI assistance to the to-do app while reusing the current provider presets, model selection, API-key field, encrypted storage, and provider request path.

## AI actions

- **Capture from text:** Turn a natural-language request into an editable task draft with title, notes, due date, reminder instant, and priority. The local date and time zone are provided so relative dates and reminder times can be interpreted consistently.
- **Break into subtasks:** Suggest up to eight direct subtasks for a selected task. The user can edit or discard the suggestions before saving them.
- **Plan today:** Suggest an ordering and brief rationale for the selected open tasks. This is a proposal only and does not change task dates or priorities.

## Interaction and data rules

- AI actions are initiated by the user and use the provider configured in Settings.
- Keep the provider catalog and request configuration already exposed by `src/shared/presets.ts`, `src/core/settings.ts`, and `src/core/providers/factory.ts`; do not change provider or API-key storage formats.
- Use Electron `safeStorage` for encrypted persistence when available. Preserve the current session-only fallback when OS encryption is unavailable.
- AI calls use the existing `Provider.chat` interface with no tools. The AI feature cannot send email, change files, access integrations, or mutate tasks.
- AI output is schema-validated. Invalid or incomplete output produces a recoverable error and leaves local tasks unchanged.
- The user reviews and confirms every proposed task or subtask before it is saved. Daily-plan suggestions never mutate tasks.
- Task text sent to a configured provider is limited to the text and task fields needed for the selected action. Daily planning sends only task IDs, titles, due dates, and priorities; the UI explains that a remote provider receives that content.
- English and Turkish prompts should receive output in the language of the input where practical.
- If no provider/API key is configured, ordinary task management remains available and AI actions explain how to configure a provider.

## Not included

General chat, autonomous agents, tool calling, web research, automatic scheduling or rescheduling, background AI runs, or sending any external action.
